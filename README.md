# Sistema de Catering

Página web responsiva diseñada para un servicio de banquetes, enfocada en la automatización de cotizaciones.

### Características
* Cotizador interactivo: Calcula el total en tiempo real dependiendo del paquete elegido y la cantidad de invitados.
* Integración con WhatsApp: Toma los datos del cotizador y genera un mensaje prellenado directo a la aplicación.
* Interfaz fluida y responsiva utilizando CSS Flexbox y Grid.

### Tecnologías
* HTML5
* CSS3
* JavaScript (Vanilla)

Este proyecto es la interfaz pública para clientes. La gestión interna y administrativa de los datos está desarrollada en un sistema backend con Python y SQLite3, disponible en mis repositorios.
